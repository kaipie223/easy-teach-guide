## M1 — 会话与对话引导

### 你需要交付的

| # | 交付物 | 文件 | 验收 |
|---|--------|------|------|
| 1 | 首页（输入课程 → 创建会话） | `views/Home.vue` | 输入"Python入门" → 跳转 /chat/s_xxx |
| 2 | 对话页面 | `views/Chat.vue` | 消息列表 + 输入栏 + 侧边上传面板 |
| 3 | 消息气泡组件 | `components/chat/MessageBubble.vue` | user=右蓝 / assistant=左灰 |
| 4 | 追问卡片组件 | `components/chat/QuestionCard.vue` | 选项按钮 + 自由输入 |
| 5 | 确认面板组件 | `components/chat/ConfirmPanel.vue` | 格式化展示 + 确认/修改按钮 |
| 6 | 输入栏组件 | `components/chat/ChatInput.vue` | 文字框 + 发送 + 语音按钮 |
| 7 | SSE 流式解析 | `utils/sse.js` | 接收 SSE → 解析 ChatEvent → 逐字渲染 |
| 8 | 会话状态管理 | `stores/session.js` | sessionId / messages / addMessage |

### 关键对接

```
你的 Chat.vue → utils/sse.js → POST /sessions/{id}/chat → 接收 SSE 事件流
→ event_type="question" → 渲染 QuestionCard
→ event_type="confirm" → 渲染 ConfirmPanel
→ event_type="text"    → 打字机逐字追加
→ 收到 [DONE]          → 停止
```

### Done 标准
- [ ] 首页输入课程名 → 创建会话 → 跳转对话页
- [ ] 对话页用假数据渲染 3 轮对话正常
- [ ] SSE 真实对接后，追问卡片/确认面板渲染正确
- [ ] 打字机效果流畅
