# 成员B · 前端工程师 — 任务说明

> **你的职责：** 开发教师直接操作的网页界面。4 个页面（首页 → 对话 → 预览 → 下载），完整覆盖"输入课程主题 → 多轮对话确认意图 → 上传参考资料 → 生成课件 → 预览修改 → 下载导出"的全流程。
>
> **代码获取：** 具体代码片段见 `docs/08_代码速查手册_Code_Cheatsheet.md` 第二节（B · 前端代码）。
>
> **依赖关系：** 你的每个页面都依赖 A 提供对应 API。开发前先确认 API 可用（Swagger 或 Postman 验证）。

---

## Phase 1：环境搭建与页面骨架（Day 1-3）

---

### Day 1 — 项目初始化 + 路由骨架

#### 任务 1.1：创建 Vue 3 项目

**要求：**
- Node.js 20.15.0 LTS，pnpm ≥ 9.0
- 用 `pnpm create vite frontend --template vue` 创建
- 安装依赖：`vue-router@4` / `pinia` / `axios` / `element-plus` / `@element-plus/icons-vue`

**验证：** `pnpm dev` → 浏览器 `http://localhost:5173` → 看到 Vite 默认页。

---

#### 任务 1.2：搭建项目骨架

**要求：**
- 按上面的目录结构创建全部文件夹和空文件（`views/` / `components/chat/` / `components/upload/` / `components/preview/` / `stores/` / `utils/` / `types/`）
- 文件暂时可以为空，但 `pnpm dev` 不能报错

---

#### 任务 1.3：配置入口文件

**要求：**
- `main.js`：注册 Element Plus（中文 locale）+ Pinia + Router
- `App.vue`：只放 `<router-view />`
- `router/index.js`：定义 4 条路由（`/` → Home / `/chat/:id` → Chat / `/preview/:taskId` → Preview / `/download/:taskId` → Download），全部懒加载

**验证：** `pnpm dev` → 浏览器白屏无报错。

---

#### 任务 1.4：收集 UI 参考

**要求：** 打开 Kimi（kimi.moonshot.cn）或 ChatGPT 对话页面，截 3 张图存到 `docs/ui-reference/`。关注：追问的呈现方式、文件上传后的预览形式、生成过程的 loading 动画。

---

### Day 2 — 类型定义 + 工具封装 + 首页

#### 任务 2.1：TypeScript 类型定义

**要求：** 在 `types/index.ts` 中定义以下 interface/type，严格对应 A 的 `schemas.py`（协议文档第 2 节）：
- `SessionCreate` / `SessionInfo`
- `ChatRequest` / `ChatEvent`
- `FileType` / `FileInfo`
- `GenerateRequest` / `TaskStatus` / `TaskInfo` / `OutputFile`

**注意：** 字段名必须与后端 JSON 的 key 完全一致（后端用 snake_case，前端保持即可）。

---

#### 任务 2.2：封装 Axios 实例

**要求：** `utils/request.js`：
- `baseURL: 'http://localhost:8000/api/v1'`
- `timeout: 30000`
- 响应拦截器：自动解包 `res.data`，错误统一提取 `detail` 字段

---

#### 任务 2.3：封装 SSE 工具

**要求：** `utils/sse.js` 导出 `createChatStream(sessionId, message, onEvent, onDone, onError)`：
- 用 `fetch` POST 到 `/sessions/{sessionId}/chat`
- 通过 `ReadableStream` 逐行读取响应
- 解析 `data: {json}` 格式的行 → 调 `onEvent(parsedJson)`
- 收到 `data: [DONE]` → 调 `onDone()`
- 返回 `AbortController` 供外部取消
- **注意：** 要处理 buffer 拼接（`\n` 分割后保留未完成的行）

---

#### 任务 2.4：写首页 + Session Store

**要求：**
- `stores/session.js`：Pinia store → `sessionId` / `teacherName` / `subject` / `messages` 列表 + `addMessage()` / `clearMessages()`
- `views/Home.vue`：一个 `el-input`（课程主题输入框）+ 一个 `el-button`（"开始设计"按钮）→ 点击后调 `POST /sessions` 创建会话 → 拿到 `session_id` → `router.push(/chat/{session_id})`
- 输入框支持 Enter 键触发

**验证：** 输入 "Python程序设计入门" → 点击按钮 → URL 跳转到 `/chat/s_xxxx`。

## Phase 2：核心交互开发（Day 4-12）

---

### Day 4 — 首页对接真实 API + Chat 页面加载真实数据

#### 任务 4.1：Home.vue 对接真实 Session API

**要求：**
- 替换假数据 → 调 `api.post('/sessions', { teacher_name: '', subject })` 创建会话
- 创建成功后跳转 `/chat/{session_id}`
- 增加 loading 状态（`el-button` 的 `:loading` 属性）
- 处理创建失败（`el-message` 提示错误）

---

#### 任务 4.2：Chat.vue 加载真实会话信息

**要求：**
- 进入 Chat 页面时，从 `route.params.id` 获取 session_id
- 调 `api.get(/sessions/{id})` 加载会话信息（教师名、课程名）
- 页面标题显示课程名称
- 如果会话不存在（404）→ 显示错误提示 + 返回首页按钮

---

### Day 5 — SSE 流式对话 + 文件上传对接（核心日）

#### 任务 5.1：Chat.vue 接入真实 SSE

**要求：**
- 用户发送消息 → 先添加 user 消息到列表 → 调 `createChatStream`
- 收到 `event_type: "text"` → 在当前 AI 气泡中逐字追加（打字机效果，用 `requestAnimationFrame` 或 `setInterval` 控制速度）
- 收到 `event_type: "question"` → 新建一条 assistant 消息，渲染为 QuestionCard
- 收到 `event_type: "confirm"` → 新建一条 assistant 消息，渲染为 ConfirmPanel
- 收到 `[DONE]` → 标记流结束
- 用户点击 QuestionCard 选项 → 作为 user 消息发送（选项文本）
- 用户在 ConfirmPanel 点击"确认" → 锁定额 + 显示"生成课件"按钮
- 在 ConfirmPanel 点击"修改" → 允许继续对话

**关键细节：**
- SSE 连接期间显示"对方正在输入…"动画
- 如果 SSE 连接失败 → 显示错误提示 + 重试按钮
- 用户发送新消息时，自动中断上一个 SSE 连接（调 `controller.abort()`）

---

#### 任务 5.2：FileUploader 接入上传 API

**要求：**
- 拖拽或点击选择文件 → `FormData` 包装 → `POST /files/upload`
- 显示实时上传进度（`onUploadProgress`）
- 上传成功后添加到文件列表（显示 `FileInfo` 各字段）
- 支持 `ref_description` 输入（教师备注）→ 作为 FormData 字段一起上传
- 文件类型白名单提示（pdf/docx/pptx/jpg/png/mp4/avi）
- 大小超限提示（视频 500MB / 其他 50MB）
- 支持删除已上传文件

---

### Day 6 — 语音输入 + 课件生成触发

#### 任务 6.1：VoiceInput 组件

**要求：**
- `navigator.mediaDevices.getUserMedia({ audio: true })` 获取麦克风权限
- `MediaRecorder` 录音 → 停止时生成 WebM Blob
- `FormData` 包装 → `POST /speech/transcribe`
- 返回文字 → emit('transcribed', text) → 父组件填入 ChatInput
- 录音时显示波形动画（CSS 或简易动画），显示录音时长
- 权限拒绝时提示用户开启麦克风

---

#### 任务 6.2：触发课件生成

**要求：**
- ConfirmPanel 点击"确认生成" → `api.post('/generate', { session_id })` → 拿到 `task_id`
- 跳转到 `/preview/{task_id}`
- 写 `stores/task.js`：Pinia store → `pollTask(taskId)` 方法 → 每 2 秒轮询 `GET /tasks/{taskId}/status` → 直到 `completed` 或 `failed`

---

### Day 7 — 预览页面

#### 任务 7.1：Preview.vue 页面

**要求：**
- 进入页面 → 开始轮询任务状态
- 显示进度条（`el-progress`）+ 状态文字（"正在分析意图…" → "正在检索知识库…" → "正在生成PPT…" → "正在生成教案…" → "正在生成互动游戏…"）
- `status: "completed"` → 停止轮询 → 展示课件列表
- `status: "failed"` → 停止轮询 → 显示错误信息（`el-alert` type="error"）+ 重试按钮

---

#### 任务 7.2：三个预览组件

**要求：**
- `PPTViewer.vue`：首选方案 → 调 Office Online Viewer 或 Google Docs Viewer 以 iframe 嵌入（`https://view.officeapps.live.com/op/embed.aspx?src={download_url}`）。备选方案 → 展示文件信息 + "下载后用 PowerPoint 打开"提示。
- `DocViewer.vue`：同上方案，用 Office Online Viewer 嵌入。
- `AnimViewer.vue`：直接用 `<iframe :src="download_url" sandbox="allow-scripts">` 嵌入 HTML5 游戏。注意 iframe 尺寸适配。

---

#### 任务 7.3：修改反馈面板

**要求：** `EditPanel.vue`：
- 多行文本输入框（`el-input type="textarea"`）→ 输入修改意见
- "重新生成"按钮 → 把修改意见附加到请求中 → 重新 `POST /generate` → 创建新 task → 重新轮询
- 展示历史生成记录（同一 session 的多次生成结果列表，可切换查看）

---

### Day 8 — 下载页面 + 全流程贯通

#### 任务 8.1：Download.vue

**要求：**
- 从路由获取 taskId → 加载任务信息 → 展示课件列表
- 每个课件：文件名 + 类型图标 + 文件大小 + 下载按钮
- 下载按钮 → `<a>` 标签 `href` 指向 `GET /download/{file_id}` + `download` 属性触发浏览器下载
- 支持批量下载（逐个触发或打包提示）

---

#### 任务 8.2：全局状态处理

**要求：** 四个页面都要处理的三种状态：
- **Loading**：数据加载中 → `el-skeleton` 或 `v-loading` 指令
- **Empty**：无数据 → `el-empty` 组件 + 引导文字
- **Error**：请求失败 → `el-alert` 或 `el-result` + 重试按钮

**全局错误处理：** Axios 响应拦截器中统一处理：
- 401 → 提示"未授权"
- 404 → 提示"资源不存在"
- 500 → 提示"服务器内部错误"
- 网络断开 → `el-message` 警告

## 常见问题与排查方向

| 现象 | 可能原因 | 排查方法 |
|------|---------|---------|
| 调 API 报 CORS 错误 | A 的 CORS 配置没加你的域名 | 让 A 确认 `allow_origins` 包含 `http://localhost:5173` |
| SSE 消息粘成一大段 | buffer 分割逻辑有问题 | 检查 `sse.js` 中 `\n` 分割和 buffer 拼接逻辑 |
| 打字机效果不流畅 | requestAnimationFrame 频率太高 | 改为 `setInterval` 每 40ms 更新 |
| `pnpm build` 报错 | 通常是 import 路径问题 | 看报错定位到具体文件和行号 |
| Element Plus 样式没加载 | main.js 缺少样式 import | 确认有 `import 'element-plus/dist/index.css'` |
| 路由跳转空白 | 懒加载路径错误 | 检查 `() => import('../views/Xxx.vue')` 的相对路径 |
