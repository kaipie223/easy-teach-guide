## M2 — 文件上传与多模态解析（你是 Owner！）

> **你是这个模块的 Owner。** 教师上传的任何文件，你都能提取出文本内容供 M5 使用。

### 你需要交付的

| # | 交付物 | 文件 | 验收 |
|---|--------|------|------|
| 1 | PDF 文本提取 | `gen/parse/pdf.py` | 教材 PDF 提取前 500 字，中文正常 |
| 2 | PDF 图片提取 | `gen/parse/pdf.py` | 提取嵌入图片，保存为 PNG |
| 3 | Word 文本提取 | `gen/parse/doc.py` | 教案 Word 提取，标题层级保留 |
| 4 | 图片描述 | `gen/parse/image.py` | 含文字截图 → 返回描述含图中文字 |
| 5 | 视频关键帧提取 | `gen/parse/video.py` | MP4 → 每 10s 提取一帧 JPG |
| 6 | 视频摘要 | `gen/parse/video.py` | 关键帧 → 图片描述 → LLM 汇总 200 字摘要 |

### 关键约定（陈澜会这样调你）

```python
# 陈澜的 loader.py 中：
from gen.parse.pdf import extract_pdf_text
text = extract_pdf_text("knowledge-base/教材PDF/xxx.pdf")

# 陈澜的 fusion.py 中：
from gen.parse.video import summarize_video
summary = summarize_video("uploads/video.mp4", api_key)
```

### 关键约定（姜文杰也会调你）

```python
# 姜文杰的 orchestrator.py Step 3 中：
from gen.parse.pdf import extract_pdf_text
from gen.parse.doc import extract_doc_text
from gen.parse.video import summarize_video
```

### Done 标准（Owner 验收，目标：8/1）

- [ ] 5 本不同来源 PDF → 都能提取文本（扫描版提示"无法提取"）
- [ ] 3 份 Word 教案 → 标题层级正确
- [ ] 含文字截图 → 描述包含图中文字
- [ ] MP4/AVI/MOV 各一个 → 都能提取关键帧
- [ ] 陈澜和姜文杰都能正常 import 你的全部解析函数

## M5 — 课件智能生成（你是 Owner！最核心模块）

> **这是整个系统最核心、最复杂的模块，你是 Owner。**

### 你需要交付的

| # | 交付物 | 文件 | 验收 |
|---|--------|------|------|
| 1 | PPT 样式系统 | `gen/pptx/layout.py` | 颜色/字体/字号/边距常量完整 |
| 2 | PPT 4 种页面模板 | `gen/pptx/slides.py` | 封面/目录/内容/总结各一页，排版正常 |
| 3 | PPT Generator | `gen/pptx/generator.py` | 指令 → LLM大纲 → ≥10 页 .pptx |
| 4 | PPT 大纲 Prompt | `gen/prompts/ppt_outline.txt` | LLM 输出合理的大纲 JSON |
| 5 | PPT 内容 Prompt | `gen/prompts/ppt_content.txt` | 每页 3-5 个要点，15-30 字/条 |
| 6 | Word 教案 Prompt | `gen/prompts/doc_plan.txt` | 6 板块内容 JSON |
| 7 | Word Generator | `gen/docx/generator.py` | 指令 → ≥3 页 .docx |
| 8 | Word 板块模板 | `gen/docx/sections.py` | 每个板块有兜底模板 |
| 9 | 动画/游戏 Prompt | `gen/prompts/anim_idea.txt` | LLM 输出完整 HTML 代码 |
| 10 | 动画 Generator | `gen/anim/generator.py` | 指令 → .html，浏览器可交互 |
| 11 | 第 2 套配色方案 | `layout.py` 扩展 | academic（蓝）/ colorful（橙）两套 |
| 12 | 3 套 Demo 课件 | `output/` | 入门课/进阶课/复习课各一套 |

### 关键约定（姜文杰会这样调你）

```python
from gen.pptx.generator import gen_ppt
from gen.docx.generator import gen_doc
from gen.anim.generator import gen_animation

# 姜文杰在 orchestrator.py Step 5-7 中调用：
pptx_path = gen_ppt(instruction, output_dir="./output")
docx_path = gen_doc(instruction, output_dir="./output")
html_path = gen_animation(instruction, anim_type="quiz_game", output_dir="./output")

# 返回值都是 pathlib.Path → .pptx / .docx / .html 文件的路径
```

### 课件质量标准（Owner 把关）

**PPT（≥ 10 页）：**
- [ ] 封面：标题 + 副标题（对象/课时）+ 蓝色背景
- [ ] 目录：与 instruction.logic_flow 对应
- [ ] 内容页：每个 knowledge_point 1-2 页，标题+要点+可选配图
- [ ] 总结页：回顾全部 key_points
- [ ] 每页右下角页码
- [ ] 中文无方框□□□
- [ ] PowerPoint 打开排版不崩

**Word 教案（≥ 3 页）：**
- [ ] 6 个板块：教学目标 / 重难点 / 教学过程 / 教学方法 / 课堂活动 / 课后作业
- [ ] 教学目标为三维目标格式
- [ ] 教学过程按 logic_flow 展开
- [ ] 页边距标准 A4，字体 12pt，行距 1.5 倍
- [ ] Word 打开排版正常

**HTML5 动画/游戏：**
- [ ] 浏览器打开可交互（答题/动画/闯关等）
- [ ] 中文正常，不依赖被墙 CDN
- [ ] Chrome / Edge 均正常

### Done 标准（Owner 验收，目标：8/12）

- [ ] 同一指令生成 3 次 → 3 次都成功（成功率 ≥ 95%）
- [ ] 姜文杰正常 import gen_ppt / gen_doc / gen_animation 且不报错
- [ ] 姜文杰的 orchestrator 完整链路（Step 1-6）跑通一次
- [ ] 3 套 Demo 课件（入门/进阶/复习）全部生成成功
