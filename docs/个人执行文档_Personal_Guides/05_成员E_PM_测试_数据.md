### 全链路端到端测试脚本（Day 11-12 执行）

```
1. 打开浏览器 → http://localhost:5173
2. 输入"我想备一节Python列表操作课，大一新生，45分钟"→ 点击"开始设计"
3. 进入对话页面，发送消息
4. 验证 AI 追问（对象、课时等）→ 回答追问
5. 验证 AI 确认总结 → 点击"确认"
6. 上传一个 PDF（参考教材某章）→ 备注"参考格式"
7. 点击"生成课件"
8. 等待生成（观察 loading 动画）→ 轮询完成
9. 进入预览页面 → 逐页浏览 PPT → 浏览 Word 教案 → 试玩 HTML 游戏
10. 输入修改意见"把第3页简化一点" → 点击"重新生成"
11. 验证修改生效
12. 下载 .pptx / .docx / .html → 用本地软件打开，确认内容正确
```
