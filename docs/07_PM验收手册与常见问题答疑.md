## 〇、PM 每日工作节奏（10 分钟模板）

```
09:00  看一遍 Sprint Board → 标记今天到期项 → 群内发"今日任务提醒"

17:00  主动找每个人要今日产出物 → 对照本文档的验收标准逐项检查

21:10  更新 Sprint Board + 在群里发"今日完成情况小结"
```

### 环境问题（Phase 1 高频）

| 问题 | 谁可能遇到 | 你怎么回答 |
|------|-----------|-----------|
| "poetry 不是内部命令" | A/C/D | `pip install poetry==1.8.3`，装完关掉终端重开 |
| "Python 版本不对，我是 3.12" | A/C/D | Python 3.12 可能导致部分依赖不兼容。用 `pyenv` 或从 python.org 下载 3.11.9 安装，装在另一个目录，用 `py -3.11` 启动 |
| "pip install 报 SSL 错误" | A/C/D | 网络问题。让他试试 `pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org <包名>` |
| "pnpm 不是命令" | B | `npm install -g pnpm@latest` |
| "DeepSeek API 调不通" | C/D | 先让他检查 `.env` 中 Key 是否正确。再让他 `curl https://api.deepseek.com/v1/models` 看网络通不通。如果返回 401 → Key 无效。如果超时 → 网络问题，可能需要代理 |
| "ChromaDB 报 sqlite3 错误" | C | 可能是 Python 3.11 的 sqlite3 版本问题。让他 `pip install pysqlite3-binary` 然后代码里加 `__import__('pysqlite3'); import sys; sys.modules['sqlite3'] = sys.modules.pop('pysqlite3')` |
| "faster-whisper 下载模型失败" | C | 首次运行时会下载 ~1GB 模型。如果下载慢 → 让他从镜像站手动下载放到 `~/.cache/huggingface/hub/` |

---

### 接口对接问题（Phase 2 高频）

| 问题 | 谁可能遇到 | 你怎么回答 |
|------|-----------|-----------|
| "import backend.schemas 报 ModuleNotFoundError" | C/D | 确认项目根目录在 Python path 中。让他 `export PYTHONPATH="${PYTHONPATH}:."` 或在项目根目录执行。或者在 `pyproject.toml` 中配置 |
| "A 的 API 返回格式和我预期不一样" | B | **这是协议文档不一致的问题**。让他们对照 `docs/01_技术协议与接口规范_Technical_Protocol.md` 对应章节 → 谁偏离了谁改 |
| "我的函数 A 调不了，参数不对" | C/D | 检查函数签名是否和协议文档第 4 节一致。如果 A 需要额外参数 → 先更新协议文档 → 再改代码 |
| "SSE 前端收到的是乱码/不完整" | B | 3 个可能：① A 的 SSE 格式不对（没有 `data: ` 前缀）② A 没有 `\n\n` 结尾 ③ B 的解析逻辑有问题。让他们各打日志调试 |
| "Postman 调 SSE 看不到流式输出" | A/B | Postman 对 SSE 支持不好。用 curl 测试：`curl -N -X POST http://localhost:8000/api/v1/sessions/{id}/chat -H "Content-Type: application/json" -d '{"message":"你好"}'` |
| "PPT 生成的中文变成方框□□□" | D | 字体问题。让他检查 `layout.py` 中的 `FONT_TITLE` 和 `FONT_BODY`，改成系统确实有的中文字体（`微软雅黑`/`宋体`/`SimSun`/`SimHei`） |
| "多个请求同时发，系统崩了" | A | SQLite 不支持高并发写入。加锁或者排队。短平快的方案：`threading.Lock` 包住所有写 DB 的操作 |

### LLM 调优问题（Phase 2-3 高频）

| 问题 | 谁可能遇到 | 你怎么回答 |
|------|-----------|-----------|
| "LLM 返回的 JSON 格式不对，pydantic 解析报错" | C/D | 让他在 Prompt 里加上 `输出严格的 JSON 格式，不要输出任何其他内容`。再加 `response_format={"type": "json_object"}`。如果还不对 → 减少 JSON 层级，先让 LLM 只输出核心字段 |
| "LLM 生成的内容质量差" | C/D | 检查 Prompt 是否给了足够的上下文（few-shot 示例/约束条件/输出格式）。让他把实际输出和预期输出对比，找到差距再改 Prompt |
| "LLM 调用超时" | C/D | 设置 `max_tokens` 不要太大（PPT 大纲 2000，教案 3000，动画 4000 够用）。timeout 设 60 秒 |
| "token 消耗太快" | C/D | 检查是否把全量对话历史每次都发给 LLM → 只保留最近 10 轮。RAG 检索的 top_k 不要超过 5。 |

### 前端问题（Phase 2-3 高频）

| 问题 | 谁可能遇到 | 你怎么回答 |

| "SSE 连接一直 pending" | B | 先确认 A 的服务是否在运行。再确认后端 SSE 路由是否用了 `StreamingResponse` |
| "element-plus 样式没加载" | B | `main.js` 中确认有 `import 'element-plus/dist/index.css'` |

| "vite build 报错" | B | 通常是 import 路径大小写问题或未使用的变量。看报错信息定位文件 |

## 六、各模块常见缺陷速查表

> 当你测试时发现不符合预期，快速定位到可能的根因。

### 对话功能

| 现象 | 可能原因 | 找谁 |
|------|---------|------|
| 发消息后没回复 | A 的 Chat SSE 没调 C 的 analyzer | A |
| 回复内容与问题无关 | C 的 Prompt 缺少上下文 | C |
| 追问选项不合理（比如问"你喜欢什么颜色"） | C 的 follow_up.txt Prompt 缺少教学领域约束 | C |
| 确认总结漏了知识点 | C 的 intent_extract.txt 中 knowledge_points 提取不全 | C |
| SSE 消息粘在一起（前端一次输出一大段） | B 的 SSE 解析 buffer 处理有问题 或 A 没有逐条 flush | A+B |
| 打字机效果卡顿 | B 的 requestAnimationFrame 间隔太短 | B |

### 文件上传

| 现象 | 可能原因 | 找谁 |
|------|---------|------|
| 上传后返回 422 | A 的文件类型校验太严格 | A |
| 上传成功但列表不显示 | B 的 FileUploader 没有正确更新文件列表 | B |
| PDF 解析出乱码 | PDF 是扫描版 + D 的 PyMuPDF 没法处理扫描版 | D |
| 视频上传后解析失败 | FFmpeg 没装好，cv2 读取失败 | D |
| 大文件上传超时 | A 的 Nginx/uvicorn 没配置文件大小限制 | A |

### 课件生成

| 现象 | 可能原因 | 找谁 |
|------|---------|------|
| PPT 只有 3 页 | D 的大纲 Prompt 没有要求最少页数 | D |
| PPT 内容不完整（某页只有标题没内容） | LLM 输出被截断，max_tokens 太小 | D |
| Word 教案缺少某板块 | D 的 doc_plan.txt Prompt 没有要求全部 6 个板块 | D |
| 动画打不开 | HTML 代码不完整或引用了外部 CDN（没网就打不开） | D |
| 生成的课件和教学目标不匹配 | C 的 fusion 环节没把意图正确传递给指令集 | C |
| 两次生成完全一样 | C 的 fusion 没有加入随机性（temperature=0） | C |

### 下载

| 现象 | 可能原因 | 找谁 |
|------|---------|------|
| 点下载显示 404 | A 的 file_id 和实际文件路径没对上 | A |
| 下载的文件打不开 | 生成时就损坏了（0KB 或格式错误） | D |
| 下载文件名是乱码 | Content-Disposition header 编码问题 | A |
